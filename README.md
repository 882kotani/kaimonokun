# 🛒 買い物メモ（家族共有アプリ）

Node.js + Express で動作する、シンプルで使いやすさを重視した家族共有の買い物メモアプリです。  
スマホ操作に最適化されており、家族間でリアルタイムに買い物リストを共有・編集できます。

---

## ✨ 主な機能

- **買い物リストの基本操作**
  - **追加・編集・削除**: 買うものをサクッと追加。二重タップや押し間違いを防ぐシンプルな操作感です。
  - **購入済みチェック**: チェックを入れるとグレーアウト＋打ち消し線が表示されます。
- **ドラッグ＆ドロップで並び替え**
  - リスト内のアイテムを長押し・ドラッグすることで、買う順番や優先度に合わせて自由に並び替えられます。
- **よく買うもののテンプレート機能**
  - **トップ画面から1タップでコピー**: 「牛乳」「卵」など定期的に買うものをテンプレートとして登録しておけば、トップ画面の「テンプレートをコピーする」ボタンから一括追加できます（既にリストにある未購入品は重複追加されません）。
  - **テンプレートの自由編集**: 「テンプレートを編集」パネルを開くことで、雛形アイテムの追加・変更・削除がいつでも行えます。
- **一括削除機能**
  - **購入済みを削除**: 買い終わったチェック済みの商品だけをまとめて消去します。
  - **すべて削除**: リスト全体を一度にクリアします（誤操作防止の確認ダイアログ付き）。
- **家族間での自動リアルタイム同期**
  - 4秒ごとの自動ポーリングにより、別の部屋やスーパーにいる家族が更新した内容も自動で画面に反映されます。

## 📁 フォルダ構成

```text
shopping-memo/
├── data/
│   ├── items.json       # 買い物リストのデータ保存先
│   └── template.json    # テンプレート（雛形）のデータ保存先
├── public/
│   ├── index.html       # メイン画面（UI構造）
│   ├── style.css        # スタイル・デザイン定義
│   └── app.js           # フロントエンド処理（ドラッグ操作・同期など）
├── package.json         # 依存パッケージ管理
├── server.js            # Webサーバー & APIエンドポイント
└── README.md            # 本ドキュメント
```
